Quiet Feed settings

Model

Jev runs in TypeSafe's cloud with your API key. GLiNER2.5-Decide runs on this computer with no key. GLiNER2.5 by Fastino is an early API option that will switch to Decide once Fastino hosts it.

Local model

Runs fastino/GLiNER2.5-Decide on this computer; post text never leaves it. Optional: the extension works without it. Quiet Feed switches to it only after the server answers.

Start it with cd local-server && .venv/bin/python -m quiet_feed_local (setup steps are in the README).

What gets sent, and where

When filtering is on, Quiet Feed sends each post it evaluates on your X home timeline to the model you picked above, using your API key: the post text, any quoted-post text, image descriptions and labels, whether a video is attached, and the wording of the filters and topics you enabled. GLiNER sends to Fastino (api.fastino.ai); Jev sends to TypeSafe (api.typesafe.ai).

Fastino says it trains on customer data unless you are on a Pro or Custom plan and opt out.

It does not send direct messages, drafts, cookies, your account details, or anything else on the page. Decisions are cached on this device for 24 hours as hashes and scores; post text is not stored in that cache. The last 50 hidden posts (author, first 280 characters, reason) are kept in memory so you can review them in the popup; that list is erased when the browser closes.

AI video filtering is based on text and labels only. Quiet Feed cannot see video footage.

API keys

"Remember" stores keys in this extension's local storage, readable only by the extension's own pages and service worker. It is not encrypted and is never synced or exported.

Custom topics

Each topic is judged separately. Exceptions keep matching posts visible, for example "Hide cryptocurrency price speculation; keep technical blockchain research."
